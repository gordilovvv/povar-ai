# Новая вечеринка

Вечеринка — строка в `party` + строка в `party_time`. Агент читает их inner join'ом: видна любая, у которой `party_end_at >= now()`, включая заведённые наперёд. Черновик = `party` без `party_time`: строку в `party_time` вставляем, только когда готовы анонсировать.

Пишем напрямую через `./scripts/db.sh`, кода под это не заводим.

## Чего не хватает — спроси

Перед insert собери обязательное, не выдумывай: название, тип (`owned` — наша, `invited` — нас позвали), дату, время старта и конца по Дубаю, цену и правила входа, локацию. Опциональное (ссылка на карту, reels, столы) — спроси один раз списком; не дали — оставляй null, заглушки не пишем.

## party

- `id` — слаг: название в snake_case + `_MM_DD` даты по Дубаю. Он же `party_id` во всех связанных таблицах, после создания не меняется.
- `price` — numeric в AED; бесплатный вход = `0`, не null.
- `marketing_message` при создании не заполняем — это отдельный флоу рассылки, стартует позже.

## Время: Дубай → UTC

Пользователь называет время по Дубаю (UTC+4), в базе `timestamptz` в UTC. Вставляй литералом с явной зоной и проговори пользователю обе версии перед insert — молчаливый сдвиг на 4 часа хуже лишней строки в ответе.

- `party_start_at` — старт.
- `party_end_at` — конец. Без него агент вечеринку не видит.
- `free_entry_before` — граница бесплатного входа/гест-листа. Бесплатного окна нет — ставь равным `party_start_at`; гест-лист работает до конца — ставь время конца.

## notes

Свободный текст, который агент пересказывает гостям, — единственный источник фактов, не покрытых колонками. Пиши плотными фактами, без маркетинга: время старта и конца, правила входа и гест-листа, лайнап и время сетов, дресс-код, описание площадки, бытовые факты, о которых гости реально спрашивают. Чего в notes нет — того агент не знает; факты в notes не должны противоречить колонкам.

## Опциональные таблицы

- `party_tables` (`prices` jsonb, `map`) — только если продаём столы и цены известны.

## Проверка

После insert прогони select тем же join'ом, что у агента, и сверь: слаг, тип, цена, оба таймстампа в UTC, notes без противоречий с колонками. Правил поведение агента вокруг вечеринки — дальше скилл `e2e-whatsapp-test`.
