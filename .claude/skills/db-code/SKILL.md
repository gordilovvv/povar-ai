# DB-код

Стек: `pg` + `pg-format`. Node нативный TS без транспайла.

## Storage layer (папка db/)

Один файл на таблицу, kebab-case. Только запросы — без бизнес-логики, без try-catch, без SQL-конструкторов. Пул импортируем из локального `db.ts`.

### Интерфейс {Name}Storage
Колонки БД as-is: snake_case, типы pg (`string`, `string | null`). Enum-подобные колонки — отдельный union-`type`, не голый `string`.

### Функции
- Первым аргументом всегда `client: PoolClient`, дальше остальные аргументы. Запрос через `client.query(...)`, не `pool.query(...)` — соединение прокидывается снаружи, чтобы функции работали внутри транзакции.
- Стрелочные через `export const`
- Без возвращаемого типа
- Параметризация только `pg-format` + `%L`
- Нейминг по операции: `select` / `insert` / `update` / `delete`. Полные описательные имена, `Id` в суффиксе можно опускать.
- Null-check через `result.rows.length ? ... : null`, не `?? null`
- Даты конвертируем через `fromDateTime` из `lib/fmt`
- Пагинация — keyset через `lastId` + `limit`, не `offset`. `lastId` nullable (первая страница — `null`), сравнение делаем одной веткой SQL, без `if` в коде.
- `insert` по дефолту ничего не возвращает (без `returning`). `returning` добавляем только если логика требует значения.
- Короткий SQL — одной строкой. Длинный (вставки, многострочные select) — многострочным template literal: ключевые слова (`insert into` / `values` / `returning`) на отдельных строках, списки колонок и значений с отступом.

### Импорты внутри проекта
Реальное расширение `.ts`, не `.js` и не без расширения. Включён `allowImportingTsExtensions`.

## Миграции (SQL)

Схему накатываем руками. Стиль:
- Все ключевые слова и типы в lowercase: `primary key`, `not null`, `references`, `bigserial`, `jsonb`, `timestamp with time zone`
- `timestamp with time zone`, не `TIMESTAMPTZ`
- Не ставим `not null`/`default` без явной необходимости — колонки nullable, дефолты задаём на уровне приложения
- Enum-подобные колонки документируем inline-комментом `-- value_1 | value_2`
- Индексы через `create index if not exists`
