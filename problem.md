# text outside tool

**Цифры:** 6 из 72 ходов за сутки (8%). Все 6 — реплики «спросить и ждать» без `save_guest`; там, где был `save_guest`, сбоев 0. Гость всегда получал ответ (nudge спас), цена — +4–6 с и лишний запрос.

**Корневая причина:**

```
история чата в buildMessages:
  guest: "Yes pls"                          ← user
  sema:  "Want me to add you..."            ← assistant, PLAIN TEXT (без tool_use)
  ...
→ модель видит few-shot «бот отвечает текстом»
→ на коротком «Let me ask» пишет текст и считает его отправленным
```

Правило «только через send_message» — лишь в кэшированной шапке, в хвосте запроса напоминания нет. `tool_choice`/thinking ни при чём.

**Правки (дешёвая → дорогая):**
- A. Харнес (`Agent.ts`): текст без тула → сразу отправить через `sendMessages` + WARN, без nudge.
- B. Напоминание в конце запроса (`role: 'system'` после последнего сообщения гостя), ~40 токенов.
- C. Nudge переписать: явно «твой текст НЕ дошёл».
- D. Историю бота рендерить как `tool_use`+`tool_result` — лечит причину, нужен полный прогон проб.
- Не делать: `tool_choice: any` (400 на Fable 5.1).

**Проверка:** ≥100 ходов step 0 пробами (`tsx --conditions=development`), метрика `text outside tool` = 0.
