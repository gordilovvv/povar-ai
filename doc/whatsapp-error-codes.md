# WhatsApp Cloud API — коды ошибок

## Структура ошибки

```json
{
  "error": {
    "message": "(#130429) Rate limit hit",
    "type": "OAuthException",
    "code": 130429,
    "error_data": {
      "messaging_product": "whatsapp",
      "details": "Cloud API message throughput has been reached."
    },
    "error_subcode": 2494055,
    "fbtrace_id": "Az8or2yhqkZfEZ-_4Qn_Bam"
  }
}
```

**Логику обработки ошибок строить вокруг `code` и `error_data.details`.** Поле `message` содержит заголовок и будет упразднено. `error_subcode` не используется в v16.0+.

Ошибки приходят двумя путями:
- **Синхронно** — в теле ответа Graph API
- **Асинхронно** — через Webhooks (`entry.changes.value.errors` или `entry.changes.value.messages.errors`)

## Ошибки аутентификации

| Код | Причина | Решение |
|-----|---------|---------|
| `0` | Токен недействителен или истёк, или пользователь запретил доступ | Получить новый токен |
| `3` | Проблема с разрешениями приложения | Проверить через отладчик токена |
| `10` | Разрешение не предоставлено или удалено | Проверить разрешения приложения |
| `190` | Срок действия токена истёк | Получить новый токен |
| `200` | Токен не передан в запросе | Добавить `Authorization: Bearer <token>` |
| `200–299` | Разрешение не предоставлено или удалено | Проверить через отладчик токена |

## Ошибки целостности аккаунта

| Код | Причина | Решение |
|-----|---------|---------|
| `368` | WABA заблокирован за нарушение правил платформы | Проверить документ «Меры по обеспечению соблюдения правил» |
| `130497` | Отправка в данную страну ограничена | Проверить Политику в отношении бизнес-переписок |
| `131031` | WABA заблокирован или неверный PIN двухшаговой проверки | Health Status API + документ о мерах соблюдения правил |

## Ошибки ограничения скорости

| Код | Причина | Решение |
|-----|---------|---------|
| `4` | Превышен лимит вызовов API на уровне приложения | Retry позже, снизить частоту запросов |
| `80007` | Превышен лимит WABA | Retry позже |
| `130429` | Превышена пропускная способность Cloud API | Retry с exponential backoff |
| `131048` | Телефонный номер ограничен из-за спам-жалоб | Проверить качество в WhatsApp Manager |
| `131056` | Слишком много сообщений одному получателю за короткое время | Подождать перед повторной отправкой тому же номеру |
| `131064` | Превышен лимит переписок из-за нарушений классификации шаблонов | Ограничение снимается автоматически; проверить качество шаблонов |
| `133016` | Слишком много попыток регистрации/отмены регистрации номера | Повторить после разблокировки |

## Прочие ошибки

| Код | Причина | Решение |
|-----|---------|---------|
| `1` | Недействительный запрос или ошибка сервера | Проверить status-page; убедиться в правильности запроса |
| `2` | Временный сбой (высокая нагрузка) | Проверить status-page, retry |
| `33` | Номер телефона компании удалён | Проверить корректность номера |
| `100` | Неподдерживаемые или неверно написанные параметры | Проверить справочник эндпоинта |
| `135000` | Неизвестная ошибка в параметрах запроса | Проверить синтаксис; обратиться в поддержку при повторении |

## Ошибки Marketing Messages API (MM Lite)

| Код | Описание | Решение |
|-----|---------|---------|
| `100` | Сообщение должно быть шаблонным | Использовать тип `template` |
| `131009` | Недопустимый параметр или синхронизация рекламы не завершена | Подождать 10 минут, retry |
| `131055` | Только маркетинговые шаблоны поддерживаются | Использовать шаблон категории `MARKETING` |
| `132018` | Ошибка валидации шаблона | Проверить параметры шаблона |
| `134100` | Категория шаблона не `MARKETING` | Сменить категорию |
| `134101` | Шаблон ещё синхронизируется (до 10 мин) | Подождать 10 минут |
| `134102` | Шаблон недоступен / нет соответствия требованиям | Проверить `marketing_messages_lite_api_status` |
| `1752041` | Дублирующийся запрос на подключение | Первый партнёр уже отправил запрос — дополнительных действий не нужно |

## Быстрый гайд для sema

| Ситуация | Код | Действие |
|----------|-----|---------|
| Напоминание не дошло | `131049` | Повторить через 24ч; проверить качество шаблона |
| Пользователь отписался | `131050` | Не слать; пометить в БД; слушать Webhook `user_preferences` |
| Окно 24ч закрылось | `131047` | Переключиться на шаблонное сообщение |
| Номер не в WhatsApp | `131026` | Пометить в БД; не повторять |
| Rate limit | `130429` | Exponential backoff; снизить частоту |
| Токен истёк | `190` | Обновить системный токен |
| Проблема с оплатой | `131042` | Проверить кредитную линию в WABA |
