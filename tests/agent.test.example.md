# Формат пробы генеративного агента

Эталон формата для проб промпта. Это **не автотест**: булев гейт на генеративной системе
врёт — один и тот же промпт в двух прогонах даёт `OK` и `FAIL`. Инструмент печатает частоту
слома, а решение принимает читатель.

Оптимизирован под чтение агентом-разработчиком: зелёный прогон стоит одну строку.

## Вывод

Зелёный вариант — всё, что печатается:

```
OK   good sys@17aae8 r3 5rules(0na) 14s
```

Красный — заголовок, маршруты, по строке на слом:

```
FAIL double_call sys@ed6095 r3 5rules(1na) 15s
T bot_question ∅×3
T name_given s{Игорь Гордилов},s{Игорь Гордилов}×3
F once:trace 3/3 name_given#0,1,2 n=2 [{"first_name":"Игорь","last_name":"Гордилов"}]
NA digits
```

## Строки

**Заголовок**

```
FAIL <вариант> sys@<хэш> r<повторов> <N>rules(<M>na) <время>
```

`sys@<хэш>` — sha256 system-промпта, 6 символов. Разный хэш = прогоны несравнимы,
сравнивать сигнатуры можно только внутри одного хэша.

**`T` — трейс-гистограмма**, по строке на сценарий, только на красном

```
T <сценарий> <маршрут>×<N> | <маршрут>×<M>
```

Маршрут — тул-вызовы по порядку: первая буква имени тула + аргументы в `{}`, `∅` если тулов
не было. Несколько маршрутов через `|` означают, что модель плавает между ними; это видно
без чтения текста ответа.

**`F` — слом**

```
F <id>:<тир> <сломалось>/<наблюдаемо> <сценарий>#<повторы> <улика>
```

`3/3` — слом стабильный. `1/3` — разброс генерации, а не поломка промпта. Улика одна:
три парафраза одного слома стоят токенов и не добавляют фактов.

**`NA`** — правила, ненаблюдаемые в этом прогоне. Считает харнес из `observable()`, не
разметчик руками.

## Тиры

Тир в `F`-строке говорит, насколько верить самому детектору.

| тир | сигнал | риск |
|---|---|---|
| `trace` | тул-вызовы, их число, аргументы, порядок | нет |
| `deny` | запрет по закрытому словарю | ложный pass невозможен |
| `oblig` | обязательство по словарю | **ложный fail на парафразе** |
| `derived` | вычисляемый инвариант | зависит от источника |
| `judge` | LLM-судья, forced tool | дорого и врёт, последнее средство |

Порядок выбора: `trace` → `deny` → `derived` → `oblig` → `judge`. Правило уходит на тир
ниже, только если на верхнем оно физически ненаблюдаемо.

Замер на полигоне (24 прогона, 4 варианта промпта, 3 правила): `trace` — 0 ошибок,
`deny` — 0 ошибок, 0 токенов; `judge` — 24 141 токен, 58 сек и 2 ложных pass на семантическом
уклонении. Транскрипт-дамп — 3489 символов и никакого вердикта.

## Правило

```ts
export interface Rule {
    id: string;
    tier: Tier;
    /** Ложь → правило в этом прогоне физически ненаблюдаемо, харнес ставит NA сам. */
    observable: (run: Run) => boolean;
    check: (run: Run) => { pass: boolean; ev?: string };
}
```

`observable` обязателен и обязан быть честным. Правило про текст ненаблюдаемо, когда модель
ответила пустым текстом и одним тул-вызовом; правило про тул — когда сценарий до тула не
доходит. Без этого статуса ненаблюдаемые пары превращаются в ложные сломы: на первом замере
так возникли 4 расхождения из 6.

## Структурные сигналы

Дёшевы, детерминированы, не требуют разбора естественного текста:

- число вызовов тула и его аргументы;
- инварианты порядка: `save_guest` только после имени в диалоге, после `pause_chat` нет отправки;
- эффекты в БД: строка создана ровно один раз, дублей нет;
- цифры: числовой токен в ответе обязан быть подстрокой выдачи тула или промпта — цифра из
  ниоткуда есть выдумка;
- повтор вопроса: n-gram Jaccard вопросительных предложений с предыдущими репликами;
- словарные линтеры: эмодзи вне whitelist, ссылки вне allowlist, markdown-артефакты,
  утечка n-gram системного промпта в ответ;
- форма: число сообщений за ход, длина, пустой текст при тул-вызове, доля кириллицы к латинице.

## Границы

Формат проверен на полигоне, где все правила лексические либо структурные — то есть удобные
для `trace` и `deny`. Вывод «структура и словарь несут почти всё» на этом наборе доказан,
на прод-правилах вроде «не выдумывать факты» и «не спамить повтором» — нет. `derived`-сигнал
по цифрам на реальном источнике фактов (`get_party`) не замерялся.

Реализация: `tests/probes/arena/`.
